# FalsifyRL AutoScientist-Adapted Dataset

This is the exact audited Adaptive Data export used to train the FalsifyRL AutoScientist model.
`train.csv` is the immutable exported training artifact; its SHA-256 digest and Adaption dataset/run
identifiers are recorded in `adaptation-audit.json` and `release-manifest.json`.

FalsifyRL trains a critic to identify and repair proxy-reward failures in embodied multi-agent
reinforcement learning. Each input includes a task specification, declarative reward program, and
two-agent episode trace. Each target is a strict JSON diagnosis with evidence, responsible agents,
a counterexample configuration, and an executable reward patch.

## Integrity audit

Before this bundle can be prepared, every adapted row must pass all of these checks:

1. map to exactly one of the 2,560 verified source training prompts,
2. parse as the exact eight-key diagnosis JSON schema,
3. preserve the simulator-derived verdict, failure class, responsible agents, evidence steps,
   counterexample configuration, and executable patch,
4. cover every source training prompt exactly once.

Explanatory wording and confidence may change during adaptation; executable scientific labels may
not. The original pre-adaptation rows are included as `source_train.csv` for provenance.

## Split isolation

| Split | Scenario families | Examples |
| --- | --- | ---: |
| train | `dual_arm_workspace`, `warehouse_handoff` | 2,560 |
| validation | `cooperative_transport` | 640 |
| test | `crossing_navigation` | 640 |

The held-out `crossing_navigation` family is never included in adaptation or training.

## Matched-trace design

Each vulnerable reward program appears in a pair: one aligned trace and one exploit trace use the
same reward code. A reward-code-only shortcut therefore cannot solve the verdict task. Gold labels
come from deterministic executable validators, not an LLM.

## Limitations

The scenarios are compact declarative abstractions rather than high-fidelity robot physics. This
model is a research critic, not an autonomous safety authority. All predicted patches should be
executed in a simulator and reviewed before deployment.
