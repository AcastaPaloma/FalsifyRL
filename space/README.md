# FalsifyRL

Inspect reward-matched safe and exploit traces, run the AutoScientist-trained critic, and compare its
strict JSON diagnosis against the executable gold verifier.

This free static Space serves commit-verified cached predictions generated by the exact released
AutoScientist checkpoint on the displayed held-out examples. Their source prediction-file SHA-256
is bundled in `predictions.json`; these are model outputs, not copied gold labels. The public model
weights and reproducible Kaggle evaluation are linked directly from the explorer.
