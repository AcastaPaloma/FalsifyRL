# FalsifyRL

Inspect reward-matched safe and exploit traces, run the AutoScientist-trained critic, and compare its
strict JSON diagnosis against the executable gold verifier.

The free CPU Space serves commit-verified cached predictions generated by the exact released
AutoScientist checkpoint on the displayed held-out examples. Their source prediction-file SHA-256
is bundled in `predictions.json`; these are model outputs, not copied gold labels. On hardware that
can host the selected base model, set `ENABLE_LIVE_INFERENCE=1` together with `BASE_MODEL_ID` and
`MODEL_REPO_ID` to enable fresh deterministic inference for the same examples.
